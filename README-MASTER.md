## Shared assets
Product photos, the Genmega Nova brochure PDF, and the IDM Origin router photo are loaded from `https://www.azatmexperts.com/_assets/...` on every state site, so upload them to the Arizona site once (see the Arizona package). State flag pucks (`_state_logo/xx-puck-logo.png`) are loaded from the Arizona host too, exactly as the current state sites do. Everything else (CSS, JS, SVG graphics) is self-contained in each folder.

## Rebuilding
`python3 build_all.py` (or `python3 build_all.py TX`) regenerates any site from `build_state.py`, the state's `states/XX.json`, and `palettes.json`.
